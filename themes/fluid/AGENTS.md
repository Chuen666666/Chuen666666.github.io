# Fluid 主題編輯指引

## 適用範圍

本檔案適用於 `themes/fluid/` 下的主題檔案，並補充根目錄的全域指引。

## 邊界與來源

- 此目錄是納入儲存庫的 Fluid 主題副本，包含上游程式碼與網站需要的設定。
- 一般網站設定優先修改根目錄 `_config.yml`；Fluid 專屬選項修改本目錄的 `_config.yml`。
- 單純的網站樣式或互動客製化，優先放在 `source/css/custom.css` 或 `source/js/custom.js`，避免不必要地分叉上游主題。
- 只有客製檔案與設定無法完成需求時，才修改 `layout/`、`scripts/` 或 `source/` 的主題核心檔案，並保持變更範圍最小。
- 不要以重新安裝 npm 套件或整批複製上游版本的方式覆蓋此目錄；那可能移除本站修改。

## 程式風格

- 延續鄰近檔案的 EJS、JavaScript、YAML 與 Stylus 格式及命名方式。
- 版型輸出使用者或文章資料時，保留既有 escaping 行為；使用未跳脫 HTML 前先確認資料來源可信。
- 瀏覽器端程式需避免在缺少特定 DOM 元素的頁面報錯，並考慮本站可能使用的局部頁面更新事件。
- 樣式必須同時考慮亮色、暗色、桌面與行動版；避免沒有必要的全域 selector 與 `!important`。
- 不要修改主題內的授權檔或移除原作者聲明。

## 驗證

- 執行 `npm run clean` 與 `npm run build`，留意 Fluid 警告、EJS 錯誤及 Stylus 編譯錯誤。
- 使用 `npm run server` 檢查首頁、文章、封存、分類、標籤、關於與友情連結頁面。
- 涉及視覺或互動的變更需檢查常見行動版寬度及深色模式；涉及導覽或 URL 的變更需確認自訂網域與根路徑 `/` 仍可運作。
- 若直接修改上游主題核心，交付時指出修改位置與未來升級 Fluid 時可能需要手動合併的部分。
