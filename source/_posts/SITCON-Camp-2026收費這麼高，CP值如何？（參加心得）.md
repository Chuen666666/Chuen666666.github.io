## 報名

看到課程含概了軟體工程、AI、資安這三個我都很有興趣的主題，我報名了這次的 SITCON Camp。一開始我也嘗試邀請朋友們一起參加，但因為其昂貴的報名費，他們紛紛打退了堂鼓，因此這次報名時，我基本已經做好了誰都不認識的準備。

## 五天四夜究竟幹了什麼？

這一章節你如果想仔細了解課程再仔細看就行，不然它實在篇幅相當長，可以大概看看就行，反正我把它當日記來寫。想快速了解活動值不值得參加的人，也可以考慮適當跳過這個章節，直接進到下一章內容來閱讀。

### 第一天

其實 SITCON Camp 是可以選擇提早一天入住的，畢竟活動辦在交大光復校區，作為台北人來說，實在有些遠，但我依然想多在我家床上多睡一晚，所以我就沒有選擇提前入住了，這也使得我必須早上我 5:50 就爬起來，稍作洗梳後，就去搭乘區間車和公車前往交大了。

如同預期的一樣，一到教室，幾乎沒有一個認識的，與之前 SITCON 2026 的參加經驗簡直是天差地別，叫得出名的好像只有身為工人的 [@Frank](https://frankk.uk/) 和 fearnot，但大概也就認得出來而已，真要說很熟，倒也完全談不上。

開幕過後，我們被帶往了電腦教室，迎來第一個課程——先導課程。這個課程就是由 SITCON 創始人 Denny 所教授，教了我們如 Git、GitHub、JSON 等基本概念，也說了這個營隊因為有廠商贊助，我們可以有近乎不限量的 AI Token 可以燒，我們也用 Vibe Coding 的方式，讓 AI 幫我們寫好設定好的 JSON、推上 GitHub、並用預寫好的程式來顯示每個人的簡介名片，算是一個小小練習。

接著我們又被帶回了早上那間教室吃午餐，還和 [@PGpenguin72](https://pg72.tw/) 相認了（特選群網友），之後就開始下午的廣度課程。廣度課程由兩位講者分享，第一位講者李杰穎分享了關於 AI 如何用照片構建 3D 模型的主題，甚至分享了自己的論文研究，而在如此高難度主題和午餐澱粉的雙重打擊下，一大半的人去找了周公；第二位講者的分享就有意思多了，展佑和我們分享了很多關於叢集運算的關念、AI 對程式界的衝擊等等主題，並以軟體匿名問答的方式，讓大家保持了極高的專注力在講者身上，氣氛也整個活絡了起來。

聽完了廣度課程，下一個活動是闖關活動，也是這次營隊中少數娛樂性質比較高的活動，不過雖然是這麼說，但既然是資訊的營隊，活動主題依然是緊貼著程式相關的主題，而領域涵蓋也相當廣，馮·紐曼架構、Prompt Injection、網路封包等主題應有盡有。這個活動除了為未來幾日的課程暖身外，也成為了小隊員間破冰的一大契機，雖然還是小有尷尬，但至少對對方的個性有了個底，將來相處起來也會輕鬆不少。

闖完了關，吃完了晚餐，晚上竟然還有課程。今天晚上的課程叫作網頁中的資安，由 Yoru 主講，這節課用一種很有互動性的方式，一步步教我們前後端、HTTP/HTTPS、Cookie、Session 等概念，甚至他們架了一個長得有些像 Threads 的網站，讓我們可以在上面進行一些功擊或提權等操作。雖然我已經學過裡面很大一部分的東西了，不過透過講者詳細的講解以及上機實操的練習，也讓我對網站的運作和傳輪有了更深刻的了解，這也為兩日後的課程埋下了伏筆。

結束了課程，但行程還差最後一個環節——爐邊夜談，這是一種討論的形式，讓大家可以自由選擇想聽或想聊的主題，然後一群人一起聊那個主題的內容，分享看法、聽取觀點、得到啟發，這也很好地打破了學員和主講者之間的隔閡。第一天晚上，我選了 Yoru 開的「Vibe Coding：工程師還剩下什麼？」。這一桌可謂相當受歡迎，雖然初來乍到的學員們，多少還帶著點偶像包袱，但開桌者的主持能力非常不錯，讓大家能發表自己觀點的同時，也能夠在不尷尬的情況下，把這個主題好好聊完。而我之所以選擇這桌，是因為我現在的確很常用 Vibe Coding 來實作一些 Project，但好像又沒人教過我怎麼在自身技術與 AI Agent 之間達到很好的合作平衡。我覺得這桌上最有趣的觀點是 Nathan（其中一個工人）所提的：「如同我們從 Assembly 到 C 語言，到現在更高階的程式語言，它是一種工具的進步，那會不會 AI 就只是如同前面的工具進步一樣，屬於一種工具和技術的迭代。然後，我剛講的觀點裡存在許多邏輯滑坡，所以各位可以找找看。」這一問就直接讓我陷入了深深的沉思，甚至從夜談結束到晚上休息，我都在努力地思考對這件事的看法，也算是讓夜談達成了「得到啟發」這個目的。另一件有趣的事是，我們整個活動期間的集點系統「小石系統」，竟然也是在大量 Vibe Coding 下的產物，讓我對 AI 潛力的理解又加深了許多。夜談進行得也很不錯，甚至他們還準備了豆花來給我們當點心，配上暗暗的燈光，實在是很有氛圍。

爐邊夜談是一天當中的最後一個節目，之後便是回宿舍的時間了，我們住的是交大中非常老的八舍，老、舊、髒，甚至床板透露著一股不安全感，可以說是相當差的居住環境了，不過後來也聽說這個是交大免費提供給 SITCON 團隊的，好像也就沒有什麼好抱怨的。第一天的宿舍可以說是相當安靜了，我率先詢問了大家的年紀和參加動機後，也就小聊了一陣子，整個寢室似乎就沒再出現過什麼交談了，但第一天總是如此，度過也就罷了。有趣的是，我是整間寢室年齡最大的一位，而其他人多是高中的，但也有位國中電神早早就來參加營隊了，實在是讓我佩服至極。

### 第二天

經過第二天早晨，其實也才算是體驗完營隊完整的一整天，因為今天早上我才發現，早餐竟然是在寢室裡吃的。早晨時光自由得很，只要能夠在時間內打理好一切就行了，當然這份自由，在我這種吃飯極慢的人身上，可以說幾乎是沒有了。

今天叫作「軟體工程主題日」，顧名思義就是被軟工課程轟炸的一天，講師依舊是 Denny，我們今天的目標是模擬一個救災（花蓮堰塞湖事件）的現場中，如何為救災者、遇難者、資訊整理者打造一個平台，讓大家能夠高效分工，課程主要是讓我們能夠學習使用 Vibe Coding 的方式，做一個救災幫手的網頁，不過因為是模擬，因此也僅僅只是叫我們做出個前端而已。Vibe Coding 對我來說其實不是什麼太難的技能，不過這過程中，我依然學到了如何用 MD 檔記錄 AI 行為（`log.md`）、Sub agent 如何使用、以及一些下 Prompt 的技巧等，更重要的是，我似乎有點理解作為一個寫程式的人類，在 AI 時代中應該扮演什麼角色了。

軟工課程是一整天的，從上午到晚上，全都是軟工，不過其實我們在上午和下午就已經把成果弄得差不多了，因此在晚餐過後的課程，我主要都是在和 牛排（我隊隊輔）、Yuto（我隊隊輔）以及其他別隊來的隊輔聊天，其中我對 牛排 的經歷相當有興趣，尤其對他打過 HPC 的經歷感到好奇，畢竟作為一個剛進晉初選的 HiPAC（~~但全都用 Vibe Coding~~）的選手來說，他如何學習 HPC 也是我很想知道的一件事。我和各隊輔們聊了很多，呃，有點太多了，多到被 Denny 小警告了一下。

結束課程後，又到了爐邊夜談的時間，今天我去的是由 Ak 所開的「那些年，我們一起開發（沒有人用的）軟體」，主要談的是，當你的程式作為一款產品面對市場時，它會面對什麼樣的問題，例如以前主流的瀑布開發和現在主流的敏捷開發差在哪裡、使用者選擇產品時會有什麼考量，市場可能是怎麼運作的……。其實我選擇這桌，除了它是全部主題裡看起來最有趣的之外，也是因為主持人 Ak 是一位我一直以來都很想再見到的人，上一次（也是第一次）見到他是在 SITCON 裡他的一個關於 AI 的議程，他作為講者，能讓我在這種純理論的議程中聽得如此入迷，實力可見一斑；而這次的夜談開始前，我也和他「刷臉」了一下，和他簡單聊了之前我很喜歡他議程的事情，希望經此一役，他能對我這個 AI 菜鳥有點印象。

回宿舍的生活和昨天相比，可以說有很大的不同了，雖然做的事情還是洗澡、睡覺、~~打東東~~，但和天比，今天和室友的話明顯多上了許多，也大概都混熟了，這時我才不後悔自己當初選擇跟著營隊的住宿，以及在沒朋友跟來的情況下參加這次營隊。

### 第三天

其實這幾天，我們一直有聽到颱風將近的消息，昨晚，主辦們也通知了我們，萬一今天風雨太大，我們很有可能會需要在寢室裡上線上課，好在今早的天氣還不算差，我們仍可至實體教室上課。

今天是「人工智慧主題日」，依舊在我熟悉的領域裡。今天的課程講師是 Harry 和 Ak，主要教了一些 ML、擬合、梯度、MLP、RNN 和 Transformer 等，有意思的是，許多內容採用網站互動式（遊戲式）的方式，讓我們對這些知識有想像和記憶的空間，雖然作為研究過 AI 的人，對這些自然是不陌生，但也從未有過如此清晰的理解，原本那個「反正 AI 課程講的不都是那些東西」的心態也頓時消失了，這真的不得不佩服講師的實力啊！而憑著我對這個主題的熟悉，我也問了些關於注意力機制的問題，除了解答了心中疑惑外，也順道讓講師加深一點對我的印象了。

今天一樣有廣度課程的安排，不過時間上是在晚餐前，也不知道如此安排是讓學員們更想睡覺還是更不想睡覺了。不過今天的廣度課程也是和 AI，尤其 LLM 非常相關的「AI Safety」（講師是 Ted），這個主題其實是我以前鮮有接觸的領域，也是一個我覺得我可能有點興趣的領域，大致上在談的除了 Prompt Injection 外，還有就是 LLM 的各種各樣的 Filter（過濾違禁內容的玩意兒）。雖說這主題我有點興趣，但在我強大的意志力支撐下，眼皮依然是越發沉重，只是在尚清醒的時間裡，我還是聽到了不少有意思的內容，也就不算是毫無收穫了吧？

今天上午和下午的課，都如期在教室上，只是到了晚上，因為風雨的不斷增強，主辦們只得讓我們回到宿舍上課，而這一點也不舒服，因為室友和小隊員不同，我們還得透過換寢才能進行課程，再加上線上課程很難顧及全場狀況和進度，上起來實在辛苦，也可惜了原先準備的實體活動了。

雖然沒了實體活動，但在課程結束後，他們仍多舉行了一個「預爐邊夜談」，主講者是 Ak，主要是分享一些電腦和 AI 的發展史，聽 Ak 講 AI 的主題，總能讓我聽得津津有味。預爐邊夜談似乎和原本線上的一些活動有些衝突，來聽的人似乎不多，大半還是員工呢，因此發言互動的機會多了許多，也是一個「刷臉」的好機會，最重要的是，作為這個活動第一個來和最後一個走的我來說，這給了我很好的機會和 Ak 聊天。

預完了爐邊夜談，正式的夜談便開始了，這次我選的是由 雁雁 和 Yoru 開的「開源：維護者倦怠、資安風險、商業與社群的拉扯，開源沒你想的那麼光鮮」，Yoru 算是熟面孔了，但 雁雁 還是我第一次見。這個夜談實在也是非常精彩，結合了 Yoru 作為 GitHub 有著 18K stars 的開發者與他們開源社群的經驗，這個主題實在被他們講得相當有趣，而且這次也學到了開源授權（License）的概念以及認識許多開源社群的趣事（或悲事？），算是了解了一些我平時接觸的圈子以外的東西了。

不過夜談結束後的聊天，更是我覺得今天最有價值的東西，Yoru、Ak、Nathan 這幾個大佬同時出現，和我聊了第一天夜談時，Nathan 提到的觀點，我先是提出了我的觀點：「我覺得有可能 Nathan 那段話有邏輯問題的地方在於，我想到，如果我用了 C 語言、Python 等寫了一個程式，我可以光明正大的說『這是我寫的』，但若我是用 AI 來寫，我卻不敢如此宣稱，這會不會是和那種邏輯問題有關？」但 Ak 向我解釋道：「當初 Assembly 時代，C 語言剛出現時，或許那些用 C 語言的人也不敢承認自己用 C 語言，因為更好用、方便的工具出現，使用它往往像是一種『偷懶』的行為，沒人想承認自己偷懶，所以 AI 時代還是可能經歷當初 C 語言出來時的那些循環，但我還是蠻討厭這個觀點的，老實說。」Nathan 回：「喔？可以好奇一下你討厭這個觀點的理由嗎？」「呃，首先，你們知道 Compiler 是會犯錯的嗎？它在 Compile 時會優化程式碼，而這個過程是有可能犯錯的，但這些是可預見的，Compiler 畢竟是一個 Rule-Base 的東西，但 AI 不一樣，你完全無法預測它什麼時候會犯錯。」「哇，終於有人找到我的邏輯滑坡了。」聽著他們的對話，我由衷被他們的思維和辯證感到折服，這反而是今天夜談環節裡我最有啟發的時刻了。我們聊了很久，感覺也讓那些大佬差不多記得我這張臉了吧？

一回到自己的寢室，我就看到室友的小隊輔 海鷗 在教我室友寫一個 AI 的專案，但因環境問題，程式遲遲無法跑通，我和 海鷗 便開始試著修 Code、裝環境、確認要求，還聊了許久的天，升學、Python、Rust、C++、競程、AI，把好多東西都聊了個遍，最後我們還和 海鷗 互加了 DC。海鷗 走後，我還花了許多時間，終於把室友的筆電環境和 Code 改好了，還因為這件事和 海鷗 在 DC 小聊了一陣子，今天實在是過得蠻充實的，充實到這幾乎是我營隊以來，最晚睡的一天了。

### 第四天

今天早上不知怎麼的，鼻子不受控制的一直流鼻涕，我就是被鼻涕叫醒的，睡眠品質可想而知。今天依舊颱風，原本我很期待的「資訊安全主題日」只好又在宿舍度過了。

資安大概是這個營隊的主題中，我最不熟悉的東西了，以前參加過的「大同資安體驗營」也只是學了一下三向交握、抓封包，但今天的資安課教的東西就很不一樣了，有點像是 CTF 入門的味道。上午的課程主要是由 海豹 講師教我們一些全端架構、資料庫、SSH 的概念，以及實際讓我們在他架的模擬網站上進行 SQL Injection 和 NOSQL Injection，算是真正讓我理解了 CTF 在幹嘛。

其實這個線上課程，差不多進行到下午時，就把我們要做的東西都講完了，因此晚上我們還真的不知道要幹嘛，Denny 讓講師去每間寢室給大家提問，而我們作為第一小隊，自然是頭一個「被被問的」，我們簡單提了幾個問題後，似乎課程就不關我們的事了。不過今天最大的收穫，還是和其中一位小隊員打好了關係，和他聊了很多天，原本小隊尷尬的氣圍降了不少。

爐邊夜談依然是到不同寢室的形式，其實今天的主題看起來都不是我有興趣的，只是我也沒有實力和主題能自己開一桌，索性找了個最接近資工的、由 蓋蓋 所開的「人機互動：四月中飛巴塞隆納參加人機互動國際會議的故事，來聽第一線見聞」，雖然我是玩過達明機械手臂，但人機互動是個很大的領域，因此主持人研究主題和這個無關，大概也在意料中了。這場夜談其實是我最不感興趣的，到不是主持人說得多爛，相反，我認為他的主持能力相當出色，只是我真的對他的研究方向既不了解也沒興趣，全程就當作是稍微開拓一下視野，了解還有這種領域的存在就行了。

今天晚上可以明顯感受到室友們的友好，大家聊成一片，還有人串寢來打小石系統中的對戰，是說我在營隊期間也不是很認真在玩這個系統，就當是一個話題了吧。我們室友間也拉了個 DC 群，畢竟這一覺後，我們的相處時間就只能用小時計算了。

{% img d-block mx-auto mb-4 /img/sitcon_camp_day4_1.jpg 300 "爐邊夜談" %}

### 第五天

今天早上比前幾日清閒得多，因為今天沒有主線課程，行程也比前幾天寬鬆，我們甚至享有了睡比較晚的權利。今天颱風已去，我們刷了牙、收了行李、吃了早餐，便動身前往今日課程進行處。今天上午大致介紹了一下「開源理念分享」，也就是簡單介紹 SITCON 及其他社群後，便進入到了「視界咖啡館」和「社群博覽會」的活動了。我被分配到第二梯次，這意味著社群博覽會是我的第一個活動，這個活動有點像 SITCON 外許多擺攤的一樣，去每個攤位聽聽社群理念、加入官方 DC、拿一堆看起來很厲害的貼紙貼上自己的筆電……~~大概也就最後那一個我比較有興趣吧~~。攤位數並不多，數分鐘就可以全部看過一輪，因此後來的時間，我都在外面和一群隊輔工人們聊天，雖說是聊天，但我也就靜靜在那聽著，偶爾開口兩句罷了。

緊接而來的視界咖啡館，才是今日重頭戲，這是一種討論形式，邀請業界的大咖來和我們進行聊天，有那麼一點像爐邊夜談的感覺。我們這次請到了競程界的大佬 蘇柏瑄 以及北市府資訊局局長 趙式隆，我因為對競程更有興趣，而選擇了 蘇柏瑄 那一場。他是競程出身的選手，現於香港某銀行擔任軟體工程師，「他一個月就可以賺別人的年薪。」主持人是這樣介紹他的，而他隨後的自我介紹，更是讓我佩服得五體投地：「我從小四開始就學習了程式語言，那時候是翻了一本我爸的 Java 書，覺得很好玩，就自己寫了點東西。我記得我的第一個 Project 是電腦的圈圈叉叉，那時候我還不懂得用什麼迴圈什麼的東西，就硬幹了幾百個 if-else。國中開始，我看到班級裡有人在刷 Online Judge 那種東西，覺得很有趣，就開始自己練了一下。高一的時候，我參加了資奧，然後莫名其妙就進了選訓，然後就出國比賽，就拿了銀獎；高二時我沒有拿獎，但高三時就成功拿到了金獎。」

我們一行大約十幾個人，包含 牛排，都是第二梯次選擇 蘇柏瑄 的人，開始了這場的視界咖啡館，一開始大家先是沉默，後來我與幾個人便陸續提問了幾個問題，大多也真的很有價值，甚至我解答了很多心中一直未解開的疑惑，不過我覺得最好笑的問題，屬這個：「你在學習什麼演算法時，假設遇到了一個崁，一直過不去，你會怎麼做？」看似合理的問題，蘇柏瑄 的回答卻讓人哭笑不得：「可能大概就是多刷題吧？這部分我的確是沒有什麼經驗，可能沒辦法回答到你欸。」看得出來他已經盡量保持謙虛了，但仍無法改變他與我們這種麻瓜的實力差距。

結束了如此有趣的活動，接下來就沒有行程了，主持人為小石系統上的一些成就頒了些獎，我們小隊還拿到了「占領土地最多」的獎，收穫一件前幾年的 SITCON Camp 衣服，還蠻有趣的。頒獎後，主持人也簡單做了閉幕，接下來特別開放自由時間，可以先離開，但也可以留下來到處加聯絡方式，我作為沒有 IG 的人，只得到處找工人加 DC 了，但至少這幾天我比較常看到的幾個工人的 DC 我都加上了，甚至開發組的工人 Each 還他曾在特選群裡看過我的備審，實在讓我驚訝萬分，沒想到我一個無名小卒也能被大佬發現嗎？

行程結束也快要五點了，我一路搭 Uber 再搭高鐵，回家去了。

## 收穫和結語

這次活動真的受益匪淺，如同多數我朋友說的一樣，價位上的確是相當高了，但我真的有一種值回票價的感覺，我全程能夠感受到主辦單位和工人們的用心，以及許多講者的實力。

這次活動，我做了比以往都多的社交行為，而它也為我帶來了很好的回報，我認識了很多電神，也第一次在社群中找到了歸屬感，你問我什麼樣叫作歸屬感？大概就是有著一種明天想要去當工人的衝動吧！

此外，其實我雖然已經是準資工系學生了，但我其實一直對「方向」很模糊，開發我不是專家、競程我不是專家、資安更是完全新手，什麼才是我想走的路？這次的營隊給了我答案——AI。我發現我除了對 AI 真的比較專業外，也確立了 AI，尤其是 NLP，是我感興趣的研究方向。

總而言之，我非常喜歡這次的活動，就算你沒錢參加 SITCON Camp，那麼至少明天的 SITCON 2027，你可以一起來感受一下 SITCON 大家庭的氛圍和規模！
