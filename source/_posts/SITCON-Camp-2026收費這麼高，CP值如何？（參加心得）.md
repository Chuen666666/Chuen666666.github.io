我在 7/8～7/12 參加了 SITCON Camp 2026。這是我第一次參加 SITCON Camp，但不是第一次接觸 SITCON。我同樣有參加 SITCON 2026，當時就已經相當喜歡這個組織。這次 SITCON Camp 2026 的費用雖然高達 &dollar;9,900（我買的早鳥票是 &dollar;8,900），但我仍選擇報名參加。

## 報名

看到課程涵蓋了軟體工程、AI 和資安這三個我都很有興趣的主題，我便報名了這次 SITCON Camp。一開始，我也嘗試邀請朋友們一起參加，但昂貴的報名費讓他們紛紛打了退堂鼓。因此報名時，我基本上已經做好在誰都不認識的情況下獨自參加的準備。

## 五天四夜究竟幹了什麼？

如果你想仔細了解課程內容，可以繼續閱讀這個章節；不然這部分篇幅相當長，大致瀏覽即可，畢竟我幾乎是把它當成日記來寫。想快速了解活動值不值得參加的人，也可以視情況跳過這個章節，直接閱讀下一章。

### 第一天

其實 SITCON Camp 可以選擇提早一天入住。畢竟活動辦在交大光復校區，對台北人來說實在有些遠。但我依然想在自己家的床上多睡一晚，所以沒有選擇提前入住。這也使得我必須在早上 5:50 爬起來，稍作梳洗後，便搭乘區間車和公車前往交大，事後看起來，這樣的交通方式簡直是在跟自己過不去。

如同預期，一到教室，我幾乎沒有遇到任何認識的人，和之前參加 SITCON 2026 的經驗簡直天差地別。當時叫得出名字的，好像只有身為工人的 [@Frank](https://frankk.uk/) 和 fearnot，但大概也只是認得出來而已，真要說很熟，倒也完全談不上。

開幕後，我們被帶往電腦教室，迎來第一堂課——先導課程。這堂課由 SITCON 創始人 Denny 授課，教了我們 Git、GitHub、JSON 等基本概念。他也提到，這個營隊因為有廠商贊助，我們有近乎不限量的 AI Token 可以燒。我們接著用 Vibe Coding 的方式，讓 AI 幫忙寫好符合指定格式的 JSON，再將它推上 GitHub，並用預先寫好的程式顯示每個人的簡介名片，算是一個小練習。

接著，我們又被帶回早上那間教室吃午餐，我也和 [@PGpenguin72](https://pg72.tw/) 相認了（特選群的網友）。之後便開始下午的廣度課程。廣度課程由兩位講者分享。第一位講者 李杰穎 分享了 AI 如何利用照片建立 3D 模型，甚至還分享了自己的論文研究。在高難度主題和午餐澱粉的雙重打擊下，一大半的人都去找了周公。第二位講者的分享就有意思多了。展佑 和我們分享了許多叢集運算的觀念、AI 對程式界的衝擊等主題，並以匿名軟體問答的方式，讓大家專心聽講，現場氣氛也整個活絡了起來。

聽完廣度課程，下一個節目是闖關活動，也是這次營隊中少數娛樂性質較高的活動。話雖如此，既然是資訊營隊，活動內容依然緊扣程式相關主題，而且涵蓋的領域相當廣，馮·紐曼架構、Prompt Injection、網路封包等應有盡有。這個活動除了為未來幾天的課程暖身，也成了小隊員之間破冰的一大契機。雖然還是有些尷尬，但至少大家對彼此的個性有了個底，之後相處起來也會輕鬆不少。

闖完關、吃完晚餐，晚上竟然還有課。今晚的課程叫作「網頁中的資安」，由 Yoru 主講。這堂課用了一種互動性很高的方式，一步步教我們前後端、HTTP/HTTPS、Cookie、Session 等概念。他們甚至架了一個長得有點像 Threads 的網站，讓我們在上面進行攻擊、提權等操作。雖然我已經學過裡面很大一部分的內容，不過透過講者詳細的講解和上機實作，我對網站的運作與資料傳輸有了更深刻的了解。這也為兩天後的課程埋下伏筆。

課程結束後，行程還剩最後一個環節——爐邊夜談。這是一種討論形式，大家可以自由選擇想聽或想聊的主題，再圍繞該主題分享看法、聽取觀點、獲得啟發。這也很好地打破了學員和主講者之間的隔閡。

第一天晚上，我選了 Yoru 開的「Vibe Coding：工程師還剩下什麼？」。這一桌相當受歡迎。雖然初來乍到的學員們多少還帶著點偶像包袱，但開桌者的主持能力非常不錯，讓大家能發表自己的觀點，也能在不尷尬的情況下好好聊完這個主題。我之所以選擇這桌，是因為我現在的確很常用 Vibe Coding 實作一些專案，卻好像沒人教過我，該怎麼在自身技術與 AI Agent 之間取得良好的合作平衡。

我覺得這桌上最有趣的觀點，是 Nathan（其中一位工人）所提的：「如同我們從 Assembly 到 C 語言，再到現在更高階的程式語言，這是一種工具的進步。那 AI 會不會也只是和前面的工具進步一樣，屬於工具和技術的迭代？然後，我剛剛講的觀點裡存在許多邏輯滑坡，各位可以找找看。」這一問直接讓我陷入深深的沉思。從夜談結束到晚上休息，我都在努力思考自己對這件事的看法，也算讓夜談達成了「獲得啟發」的目的。

另一件有趣的事是，貫穿整個活動的集點系統「小石系統」，竟然也是大量使用 Vibe Coding 的產物，讓我對 AI 潛力的理解又加深了許多。夜談的氣氛也很不錯，他們甚至還準備了豆花給我們當點心。配上昏暗的燈光，實在很有氛圍。

爐邊夜談是一天當中的最後一個節目，之後便是回宿舍的時間。我們住的是交大非常老舊的八舍。它又老、又舊、又髒，甚至連床板都散發著一股不安全感，可以說是相當差的居住環境。不過後來聽說，這是交大免費提供給 SITCON 團隊的，好像也就沒什麼好抱怨的了。

第一天的宿舍相當安靜。我率先詢問大家的年紀和參加動機，大家小聊了一陣子後，整間寢室似乎就沒再出現什麼交談了。不過第一天總是如此，撐過去也就罷了。有趣的是，我是整間寢室年齡最大的人，其他人多半是高中生，但也有一位國中電神早早就來參加營隊，實在讓我佩服至極。

### 第二天

到了第二天早晨，我才算真正體驗完營隊裡完整的一天。今早我才發現，早餐竟然是在寢室裡吃的。早晨的時間很自由，只要能在時限內打理好一切就行。當然，對我這種吃飯極慢的人而言，這份自由可以說幾乎不存在。

今天是「軟體工程主題日」，顧名思義，就是被軟工課程轟炸的一天，講師依舊是 Denny。今天的目標，是模擬在一個救災現場（花蓮堰塞湖事件）中，如何為救災者、受災者和資訊整理者打造一個平台，讓大家能夠高效分工。課程主要讓我們學習透過 Vibe Coding 製作一個救災幫手網頁。不過因為只是模擬，我們也僅需完成前端。

Vibe Coding 對我來說其實不是什麼太難的技能，不過在這個過程中，我依然學到了如何用 Markdown 檔記錄 AI 的行為（`log.md`）、如何使用 Sub Agent，以及一些下 Prompt 的技巧。更重要的是，我似乎開始理解，作為一個寫程式的人類，在 AI 時代應該扮演什麼角色了。

軟工課程持續一整天，從上午到晚上全都是軟工。不過，我們在上午和下午就已經把成果完成得差不多了，因此晚餐後的課程時間，我主要都在和牛排、Yuto（兩位都是我隊的隊輔），以及其他隊的隊輔聊天。

我對牛排的經歷相當有興趣，尤其好奇他參加 HPC 的經驗。畢竟對一個剛晉級初選的 HiPAC 選手（~~但全都用 Vibe Coding~~）來說，他如何學習 HPC，也是我很想知道的一件事。我和各隊輔聊了很多。呃，有點太多了，多到被 Denny 小小警告了一下。

課程結束後，又到了爐邊夜談的時間。今天我參加的是 Ak 開的「那些年，我們一起開發（沒有人用的）軟體」。這桌主要討論程式作為一款產品面對市場時，會遇到什麼問題，例如過去主流的瀑布式開發與現在主流的敏捷開發有何差異、使用者選擇產品時會考量什麼，以及市場可能如何運作……

我選擇這桌，除了因為它是全部主題中看起來最有趣的，也因為主持人 Ak 是一位我一直很想再見到的人。上一次（也是第一次）見到他，是在 SITCON 的一場 AI 議程中。他能讓我在這種純理論的議程中聽得如此入迷，實力可見一斑。這次夜談開始前，我也和他「刷臉」了一下，簡單聊了之前很喜歡他議程的事。希望經此一役，他能對我這個 AI 菜鳥有點印象。

回到宿舍後的生活和昨天相比，可以說有了很大的不同。雖然做的事還是洗澡、睡覺、~~打東東~~，但今天和室友說的話明顯多了許多，大家也差不多都混熟了。這時，我才不後悔當初選擇住在營隊安排的宿舍，也不後悔在沒有朋友陪同的情況下參加這次營隊。

### 第三天

其實這幾天，我們一直有聽到颱風接近的消息。昨晚，主辦方也通知我們，萬一今天風雨太大，很可能得在寢室裡上線上課。好在今早的天氣還不算差，我們仍可以到實體教室上課。

今天是「人工智慧主題日」，依舊屬於我熟悉的領域。課程講師是 Harry 和 Ak，主要教了 ML、擬合、梯度、MLP、RNN 和 Transformer 等內容。有意思的是，許多內容都以互動式網站（甚至遊戲）呈現，讓我們更容易想像和記住這些知識。

雖然作為研究過 AI 的人，我對這些內容自然不陌生，但從未理解得如此清晰。原本「反正 AI 課程講的不都是那些東西」的心態也頓時消失了，真的不得不佩服講師的實力啊！憑著我對這個主題的熟悉，我也問了一些關於注意力機制的問題，除了解開心中的疑惑，也順道讓講師加深一點對我的印象。

今天一樣安排了廣度課程，不過時間改在晚餐前，也不知道這樣的安排會讓學員更想睡，還是更不想睡。今天的廣度課程是由 Ted 主講的「AI Safety」，和 AI，尤其是 LLM 高度相關。這是我過去鮮少接觸、但可能會有點興趣的領域。課程除了談 Prompt Injection，也談到 LLM 各式各樣的 Filter（就是過濾違禁內容的玩意兒）。

雖說我對這個主題有點興趣，但在我強大的意志力支撐下，眼皮依然越來越沉重。好在還清醒的時候，我聽到了不少有意思的內容，也就不算毫無收穫了吧？

今天上午和下午的課都如期在教室進行。只是到了晚上，風雨不斷增強，主辦方只得讓我們回宿舍上課。這樣上課實在不太舒服，因為室友和小隊員不同，我們還得換寢才能進行課程。再加上線上課程很難顧及全場的狀況和進度，上起來實在辛苦，更可惜的是，原先準備的實體活動沒能用上。

雖然沒了實體活動，但課程結束後，他們仍額外舉行了一場「預爐邊夜談」。主講者是 Ak，主要分享電腦和 AI 的發展史。聽 Ak 講 AI，總能讓我聽得津津有味。預爐邊夜談似乎和原本的線上活動有些衝突，來聽的人不多，大半還是工人，因此發言互動的機會多了許多，也是一個「刷臉」的好機會。更重要的是，由於我是這場活動第一個到、最後一個走的人，也因此有了很好的機會和 Ak 聊天。

預爐邊夜談結束後，正式的夜談便開始了。這次我選的是雁雁和 Yoru 開的「開源：維護者倦怠、資安風險、商業與社群的拉扯，開源沒你想的那麼光鮮」。Yoru 算是熟面孔了，但雁雁還是我第一次見。這場夜談非常精彩。Yoru 是一位在 GitHub 上擁有 18K stars 的開發者，再結合他們經營開源社群的經驗，把這個主題講得相當有趣。這次我也學到了開源授權（License）的概念，還認識了許多開源社群的趣事（或悲事？），算是了解一些平時接觸的圈子以外的事物。

不過，夜談結束後的聊天，才是我覺得今天最有價值的部分。Yoru、Ak、Nathan 這幾個大佬同時出現，和我聊了第一天夜談時，Nathan 提到的觀點，我先是提出了我的觀點：「我覺得有可能 Nathan 那段話有邏輯問題的地方在於，我想到，如果我用了 C 語言、Python 等寫了一個程式，我可以光明正大地說『這是我寫的』，但若我是用 AI 來寫，我卻不敢如此宣稱，這會不會是和那種邏輯問題有關？」但 Ak 向我解釋道：「當初 Assembly 時代，C 語言剛出現時，或許那些用 C 語言的人也不敢承認自己用 C 語言，因為更好用、方便的工具出現，使用它往往像是一種『偷懶』的行為，沒人想承認自己偷懶，所以 AI 時代還是可能經歷當初 C 語言出來時的那些循環，但我還是蠻討厭這個觀點的，老實說。」Nathan 回：「喔？可以好奇一下你討厭這個觀點的理由嗎？」「呃，首先，你們知道 Compiler 是會犯錯的嗎？它在 Compile 時會優化程式碼，而這個過程是有可能犯錯的，但這些是可預見的，Compiler 畢竟是一個 rule-based 的東西，但 AI 不一樣，你完全無法預測它什麼時候會犯錯。」「哇，終於有人找到我的邏輯滑坡了。」聽著他們的對話，我由衷地為他們的思維和辯證所折服，這反而是今天夜談環節裡我最有啟發的時刻了。我們聊了很久，感覺也讓那些大佬差不多記得我這張臉了吧？

一回到自己的寢室，我就看到室友的小隊輔海鷗在教我室友寫一個 AI 專案。但因為環境問題，程式遲遲無法跑起來，我和海鷗便開始嘗試修改程式碼、安裝環境、確認需求。我們還聊了很久，從升學、Python、Rust、C++、競程到 AI，把好多東西都聊了一遍，最後還互加了 DC。海鷗離開後，我又花了許多時間，終於把室友筆電的環境和程式碼處理好了，還因為這件事和海鷗在 DC 小聊了一陣子。今天過得實在很充實，充實到這幾乎是我進營以來最晚睡的一天。

### 第四天

今天早上不知道怎麼了，鼻子不受控制地一直流鼻涕。我甚至是被鼻涕弄醒的，睡眠品質可想而知。今天颱風依舊肆虐，原本我很期待的「資訊安全主題日」，只好又在宿舍度過了。

資安大概是這個營隊的主題中，我最不熟悉的領域。以前參加「大同資安體驗營」時，也只是學了一下三向交握和抓封包，但今天資安課教的內容很不一樣，有點 CTF 入門的味道。上午的課程主要由海豹講師介紹全端架構、資料庫和 SSH 等概念，並實際讓我們在他架設的模擬網站上進行 SQL Injection 和 NoSQL Injection，算是真正讓我理解了 CTF 在做什麼。

這個線上課程進行到下午時，差不多就把所有內容都講完了，因此晚上我們還真的不知道要幹嘛。Denny 讓講師到每間寢室給大家提問，而我們作為第一小隊，自然是頭一個「被問的」。我們簡單提了幾個問題後，課程似乎就沒我們的事了。不過，今天最大的收穫還是和其中一位小隊員打好了關係。我和他聊了很久，原本小隊中的尷尬氣氛也消散了不少。

爐邊夜談依然採用分散到不同寢室的形式。今天的主題看起來都不是我感興趣的，但我也沒有足夠的實力和主題能自己開一桌，索性選了最接近資工的、由蓋蓋所開的「人機互動：四月中飛巴塞隆納參加人機互動國際會議的故事，來聽第一線見聞」。雖然我玩過達明機械手臂，但人機互動是個很廣的領域，因此主持人的研究主題與機械手臂無關，大概也在意料之中。

這場夜談其實是我最不感興趣的一場。倒不是主持人說得多爛；相反地，我認為他的主持能力相當出色。只是我真的對他的研究方向既不了解，也沒有興趣，全程就當作是稍微開拓視野，了解原來還有這樣的領域就好。

今天晚上可以明顯感受到室友們的友善。大家聊成一片，還有人串寢來玩小石系統裡的對戰。是說，我在營隊期間也沒有很認真地玩這個系統，就當作一個話題了吧。我們室友間也開了一個 DC 群，畢竟睡完這一覺後，我們的相處時間就只能用小時計算了。

{% img d-block mx-auto mb-4 /img/sitcon_camp_day4_1.jpg 300 "爐邊夜談" %}

### 第五天

今天早上比前幾天清閒得多。因為沒有主線課程，行程也比前幾天寬鬆，我們甚至享有了晚一點起床的權利。颱風已經離去，我們刷了牙、收好行李、吃完早餐，便動身前往今天的活動場地。上午首先是「開源理念分享」，簡單介紹 SITCON 和其他社群，之後便進入「視界咖啡館」和「社群博覽會」。

我被分配到第二梯次，這意味著我的第一個活動是社群博覽會。這個活動有點像 SITCON 會場外的社群攤位，可以到每個攤位聽聽社群理念、加入官方 DC，再拿一堆看起來很厲害的貼紙貼在自己的筆電上……~~大概也就最後那一個我比較有興趣吧~~。攤位數量不多，幾分鐘就可以全部看過一輪。因此後來的時間，我都在外面和一群隊輔、工人聊天。雖說是聊天，但我也就靜靜地在那裡聽著，偶爾開口說兩句罷了。

緊接著登場的視界咖啡館，才是今日的重頭戲。這是一種討論形式，邀請業界的大咖來和我們聊天，感覺有點像爐邊夜談。我們這次請到了競程界的大佬蘇柏瑄以及北市府資訊局局長趙式隆，我因為對競程更有興趣，而選擇了蘇柏瑄那一場。他是競程出身的選手，現於香港某銀行擔任軟體工程師，「他一個月就可以賺別人的年薪。」主持人是這樣介紹他的，而他隨後的自我介紹，更是讓我佩服得五體投地：「我從小四開始就學習了程式語言，那時候是翻了一本我爸的 Java 書，覺得很好玩，就自己寫了點東西。我記得我的第一個 Project 是電腦的圈圈叉叉，那時候我還不懂得用什麼迴圈什麼的東西，就硬幹了幾百個 if-else。國中開始，我看到班級裡有人在刷 Online Judge 那種東西，覺得很有趣，就開始自己練了一下。高一的時候，我參加了資奧，然後莫名其妙就進了選訓，然後就出國比賽，就拿了銀獎；高二時我沒有拿獎，但高三時就成功拿到了金獎。」

我們一行大約十幾個人，包含牛排，都是第二梯次選擇蘇柏瑄的人。視界咖啡館開始時，大家先是一陣沉默，後來我和幾個人便陸續提出問題。大多數回答都很有價值，也解開了許多一直存在心中的疑惑。不過，我覺得最好笑的問題莫過於這個：「你在學習某個演算法時，假設遇到了一道坎，一直過不去，你會怎麼做？」看似合理的問題，蘇柏瑄的回答卻讓人哭笑不得：「可能大概就是多刷題吧？這部分我的確沒有什麼經驗，可能沒辦法回答到你欸。」看得出來他已經盡量保持謙虛了，但仍無法改變他與我們這種麻瓜的實力差距。

這個有趣的活動結束後，接下來就沒有正式行程了。主持人為小石系統上的一些成就頒獎，我們小隊還拿到了「占領土地最多」的獎，收穫一件前幾年的 SITCON Camp 衣服，還蠻有趣的。頒獎後，主持人也簡單地做了閉幕。接下來是自由時間，可以先離開，也可以留下來到處交換聯絡方式。作為沒有 IG 的人，我只得到處找工人加 DC 了。不過，至少這幾天比較常看到的幾位工人，我都加到了他們的 DC。甚至開發組的工人 Each 還說，他曾在特選群裡看過我的備審，實在讓我驚訝萬分。沒想到我這個無名小卒，也能被大佬發現嗎？

行程結束時也快五點了。我先搭 Uber，再搭高鐵回家。

## 收穫和結語

這次活動真的讓我受益匪淺。就像許多朋友說的，價位的確相當高，但我真的有一種值回票價的感覺。整個過程中，我都能感受到主辦單位和工人們的用心，以及許多講者的實力。

這次活動中，我做了比以往都更多的社交嘗試，而它也為我帶來了很好的回報。我認識了很多電神，也第一次在社群中找到歸屬感。你問我什麼叫作歸屬感？大概就是有一種明年想去當工人的衝動吧！

此外，雖然我已經是準資工系學生，卻一直對未來的方向感到模糊。開發我不是專家，競程我也不是專家，資安更是完全的新手。什麼才是我想走的路？這次的營隊給了我答案——AI。我發現，自己除了對 AI 相對更熟悉，也確立了 AI，尤其是 NLP，就是我感興趣的研究方向。

總而言之，我非常喜歡這次的活動。就算預算不足，無法參加 SITCON Camp，至少明年的 SITCON 2027，你可以一起來感受 SITCON 大家庭的氛圍和規模！
