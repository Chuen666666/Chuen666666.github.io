## 動機

這次是我第一次參加 PyCon 的活動，參加的是 PyCon TW 2026。之所以會參加本次活動，也是從上一次的 COSCUP（[心得傳送門](/這是年會還是追星現場？（COSCUP參加心得）)）得知的，尤其得知高天會參加後，我沒有過多猶豫，就直接拿起卡刷下去了，沒錯，這個活動不同於以往我參加的各式年會，它是收費的，且高達兩、三千的門票也確實是不太便宜，我會來的原因大概還是有點追星的性質吧。

原本應該要和我一同前來的 [@su2u4](https://github.com/su2u4-1/)，在我與會的前一天才和我說他最後沒有報，~~所以我決定在這裡公審他~~，因此本次的 PyCon 是我第一次參加這種年會時，沒有熟人跟的。

## 與會

### Day 1

這次的 PyCon 辦在台北醫學大學，原本我以為作為世界上最多人用的語言（Python）的年會，怎麼說也得有一個規模吧？結果現場一看，當下是有點傻眼的——規模比想像中也小太多了！一共就兩層樓：四個議程廳和三個擺攤的教室。

一到現場，就看到了高天站在 R0 外，他是 Keynote 議程講者——且是開場的第一個 Keynote——我們簡單打了聲招呼，~~偷臭了一下 [@su2u4](https://github.com/su2u4-1/)~~，就準備要開場了。

開場的主持人（總召）並沒有花太多時間，很快就到了高天的 Keynote 議程「从 CPython 到 PySpark」，他分享了自已從第一個對 CPython 的 PR，到成為 CoreDev，再到現在為 PySpark 工作，除了分享怎麼對 CPython 做出貢獻、怎麼提 PR 比較容易有人看、AI 時代在開源社群中有什麼影響等，其中夾了許多他一開始對 CPython（PDB）的 PR 一些比較技術層面的東西（這也是和 COSCUP 最大的不同，畢竟 PyCon 主題就是 Python）。（對議程主題有興趣的話，可以到 [PyCon 議程表](https://tw.pycon.org/2026/zh-hant/conference/schedule)看介紹和共筆的 HackMD。

接著我繼續待在 R0，聽 Peter 分享的「從熟悉 Python 到貢獻 CPython：第一個 PR 的切入指南」，他用了一個比高天更「新手友善」的方式，說明我們如何對 CPython 社群做貢獻，尤其針對一些 built-in 函式庫（因為許多庫是用 Python 寫的，比起 C 語言更容易）。

之後，我到了擺攤的地方逛了逛，和高天以及另一個與會者聊了一下天，說起另一個與會者也是大有來頭，他是其中一位高天發布的挑戰賽（[詳情見此](https://youtu.be/smx28aI5rcY?si=fVfnmvfuI42z8C83)）的得主，也就是他的票是高天送的，可惜他只打算參與 PyCon 第一天上午就要回家了。午餐時間，Denny——沒錯，就是 SITCON 發起人那個 Denny——看到了我，還主動走過來和我聊天，~~感謝他拯救沒人陪的我~~，他和我分享了他最近自己做的一個 Project，是一個可以在 Vim 裡面預覽 Markdown 的小工具，看起來完成度還頗高，我們還聊了些大學生活的東西，畢竟作為一個大一新生，話題正是我現在的生活，總之聊得還是蠻開心的，~~就是我午餐吃有點久~~。

到了下午，我又分別聽了「打造企業級的金融 AI 服務鏈: Python 串起 ML、XAI 與 LLM 的實戰經驗」、Job Fair（各贊助企業徵才時間）、「The Insight Factory」（Keynote，雖然我也沒太聽懂）、Lightning Talks。總體而言，收獲還是不少的，但少了朋友一起跟，再加上規模又不大，到後面不免有些乏味。對了，下午提供的點心還不錯吃。

晚上還有一個自由參加的 PyNight，對於沒有人陪我參加年會的我而言，依然決定參加，萬一就這麼認識了新朋友呢？同桌的人分別有三、四位日本人、兩個台灣人（不含我）和一個在台十年以上的大馬人，一開始我們都是用英文自介和聊天，但等大部分日本人走了後，我們又轉回全中模式了，即使如此，那幾個在社會打滾一段時間的人們聊的職涯，還是和我搭不上什麼邊。
