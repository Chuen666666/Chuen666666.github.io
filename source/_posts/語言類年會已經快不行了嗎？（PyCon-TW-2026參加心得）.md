## 動機

這次是我第一次參加 PyCon 的活動，參加的是 PyCon TW 2026。之所以會參加本次活動，也是從上一次的 COSCUP（[心得傳送門](/這是年會還是追星現場？（COSCUP參加心得）)）得知的，尤其得知高天會參加後，我沒有過多猶豫，就直接拿起卡刷下去了，沒錯，這個活動不同於以往我參加的各式年會，它是收費的，且高達兩、三千的門票也確實是不太便宜，我會來的原因大概還是有點追星的性質吧。

原本應該要和我一同前來的 [@su2u4](https://github.com/su2u4-1/)，在我與會的前一天才和我說他最後沒有報，~~所以我決定在這裡公審他~~，因此本次的 PyCon 是我第一次參加這種年會時，沒有熟人跟的。

## 與會

### Day 1

這次的 PyCon 辦在台北醫學大學，原本我以為作為世界上最多人用的語言（Python）的年會，怎麼說也得有一個規模吧？結果現場一看，當下是有點傻眼的——規模比想像中也小太多了！一共就兩層樓：四個議程廳和三個擺攤的教室。

一到現場，就看到了高天站在 R0 外，他是 Keynote 議程講者——且是開場的第一個 Keynote——我們簡單打了聲招呼，~~偷臭了一下 [@su2u4](https://github.com/su2u4-1/)~~，就準備要開場了。

開場的主持人（總召）並沒有花太多時間，很快就到了高天的 Keynote 議程「从 CPython 到 PySpark」，他分享了自己從第一個對 CPython 的 PR，到成為 CoreDev，再到現在為 PySpark 工作，除了分享怎麼對 CPython 做出貢獻、怎麼提 PR 比較容易有人看、AI 時代在開源社群中有什麼影響等，其中夾了許多他一開始對 CPython（pdb）的 PR 一些比較技術層面的東西（這也是和 COSCUP 最大的不同，畢竟 PyCon 主題就是 Python）。（對議程主題有興趣的話，可以到 [PyCon 議程表](https://tw.pycon.org/2026/zh-hant/conference/schedule)看介紹和共筆的 HackMD）。

接著我繼續待在 R0，聽 Peter 分享的「從熟悉 Python 到貢獻 CPython：第一個 PR 的切入指南」，他用了一個比高天更「新手友善」的方式，說明我們如何對 CPython 社群做貢獻，尤其針對一些 built-in 函式庫（因為許多庫是用 Python 寫的，比起 C 語言更容易）。

之後，我到了擺攤的地方逛了逛，和高天以及另一個與會者聊了一下天，說起另一個與會者也是大有來頭，他是其中一位高天發起的挑戰賽（[詳情見此](https://youtu.be/smx28aI5rcY?si=fVfnmvfuI42z8C83)）的得主，也就是他的票是高天送的，可惜他只打算參與 PyCon 第一天上午就要回家了。午餐時間，Denny——沒錯，就是 SITCON 發起人那個 Denny——看到了我，還主動走過來和我聊天，~~感謝他拯救沒人陪的我~~，他和我分享了他最近自己做的一個 Project，是一個可以在 Vim 裡面預覽 Markdown 的小工具，看起來完成度還頗高，我們還聊了些大學生活的東西，畢竟作為一個大一新生，話題正是我現在的生活，總之聊得還是蠻開心的，~~就是我午餐吃有點久~~。

到了下午，我又分別聽了「打造企業級的金融 AI 服務鏈: Python 串起 ML、XAI 與 LLM 的實戰經驗」、Job Fair（各贊助企業徵才時間）、「The Insight Factory」（Keynote，雖然我也沒太聽懂）、Lightning Talks。總體而言，收穫還是不少的，但少了朋友一起跟，再加上規模又不大，到後面不免有些乏味。對了，下午提供的點心還不錯吃。

晚上還有一個自由參加的 PyNight，對於沒有人陪我參加年會的我而言，依然決定參加，萬一就這麼認識了新朋友呢？同桌的人分別有三、四位日本人、兩個台灣人（不含我）和一個在台十年以上的大馬人，一開始我們都是用英文自介和聊天，但等大部分日本人走了後，我們又轉回全中模式了，即使如此，那幾個在社會打滾一段時間的人們聊的職涯，還是和我搭不上什麼邊，不過去吃一頓免費的披薩晚餐，好像也還不錯。

### Day 2

今天比起昨天，就顯得更無聊了一點，畢竟議程中間有空閒時間外，昨天也已經把攤位全都逛過一輪了，以致於中間有一大段時間我是完全沒有事做的。

進入正題，早上先是一個 Keynote，由胡敏君（清大）教授帶來的「從數據收集到技能訓練：結合人工智慧與虛擬實境之新世代運動科技」，他和我們講了許多他們做的研究，以運動科學的角度，結合 AI（CV）的技術，進行情蒐、資料分析、訓練等，對於 AI 有點興趣的我，聽得津津有味。

之後我分別聽了「Discord 不只是聊天室：PyLadies Kaohsiung 的 Bot 實踐與社群實驗」、「Avoiding Zero-Trade Policies in RL with a Decoupled MLOps Architecture」（但講者的日本英文口音實在有點重到我聽不懂），以及午餐時間還有聽 Young Inspires（讓年輕人分享自己成功經歷的活動，分別有「從肆業到科技新貴：19 歲奇才的逆襲之路」和「打造全亞洲最大 Minecraft 技術社群——雲鎮工藝的社群經營哲學」）。其實這些演說對我而言都不算是很有興趣的了，例如介紹 PyLadies Kaohsiung 的和股票的，完全不是我原本預計會在 PyCon 聽到的、Python 相關的內容，實在有點可惜。

不過下午倒是比較好一點，我聽到了一位 Meta 員工分享的「How Static Type Checkers Understand Dynamic Python」，是介紹 Python 靜態類型檢查的技術，以及他們開發的 Pyrefly 相較於 mypy，解決了什麼問題。之後則是一位印尼人帶來的「Python eBPF: BCC C-String Runtime vs Python-BPF AST Ahead of Time」，比較了 BCC 和 Python-BPF，但這部分其實我沒有太懂就是了。不過總之，它們至少回歸到了 Python 內容，也讓我總算是有所收穫了。

下午主辦單位還安排了一段 Break Time，且主辦單位提供了比昨天更好吃（個人觀點）的下午茶。我還在這段時間裡，找到了昨天 PyNight 和我同一桌的那位馬來西亞人，聊了很多關於大學的話題，真不錯。

之後到了一個稱為「Panel Discussion」的活動，讓高天、胡敏君教授、Max（綜合醫院資訊部副主任）、YC（Noopher AI 執行長暨創辦人）四位重量級人物討論一個議題給大家聽，這次主題是「不只共存，還要生存 – AI 浪潮下的開發者求生指南」，旨在緩解我們的 AI 焦慮，更順便看看各位大佬對 AI 的看法和應用方式。其中，高天的回答每次總是能炸場，讓全場爆笑，不過四位的回答實在都讓人覺得耳目一新，非常有價值！

最後就是 Lightning Talks、抽獎、謝幕。這兩天的 Lightning Talks 都讓我有一種感覺：我要不要下次也上去試試，畢竟三分鐘，不會有任何一個人能把議題講得深，這種情況下，上去講點東西似乎也是不錯的？抽獎則是因為我忘記去拿抽獎券了，因此根本沒有我的名額，即使如此，因為贊助團隊實在給了太多書（原本作為抽獎的獎品之一），最後我們都還有書可以自由領取，實在不錯。謝幕完，也為本次活動畫下句點了，今天晚上沒有更多活動了，因此就離開回家啦！

## 心得

這次的年會畢竟就叫作 PyCon，要說沒學到 Python 的東西那是不可能的，不過如果以「票價 NTD&dollar;2,990」（早鳥票，原價 NTD&dollar;3,490）的角度衡量，這次活動實在沒有讓我值回票價的感覺——除非把它純當作是高天的粉絲見面會，那或許就很賺了，能拍照、能要簽名、能聊天。

另一個感覺如同第一天說的一樣，規模也太小了，攤位也就十來家吧，議程也就四個廳（還不一定每個廳都有議程），要是沒有朋友跟著來，那空閒的時間實在對內向的人而言不太友好。

最後，要是給別人「要不要來參加 PyCon」的建議的話，真的對 Python 很有研究、有朋友或夠外向、純粹想說試試看參加一次、有錢，我只建議符合以上至少一到兩個的人來參加，否則光是門票和體驗，就稍微有點溢價的感覺了。如果你只是一個想感受 Vibe、不只對 Python 情有獨鍾、不知道何為年會的話，那麼免費又高品質的 SITCON 或 COSCUP 都是我認為更好的選擇。

## 所以，語言類年會已經快不行了嗎？

回到這篇的標題，這其實也是第一天和 Denny 聊天時有聊到的話題。「這個規模比我想像中的也小太多了吧。」我說，Denny 回：「大概語言類的年會現在都會漸漸式微了吧。在這個 AI 的時代下，如何讓別人和企業看到程式語言本身的價值，你要如何推銷他們這很重要，這一點實在難。」Denny 也和我分享了不少 SITCON 的事：「我覺得我們當初決定要設主題是一個蠻正確的決定，有主題才能有辦法與社會共鳴。」

看來，語言類的年會式微已經是一個大概很難改變的問題了，畢竟主題就已經擺在那邊了，「定主題」這招很難直接複製貼上在這類活動中。但另一方面，人少也意味著擁有更多機會和「對 Python 很熱血」的人接觸，因此這對社群而言是壞事，但對與會者來說，也不全然。

不過雖然在世界各地的語言年會都已經沒有了當初的盛況，但由官方直接辦的 PyCon US 仍是有一定規模的，因此若未來有機會，我反而覺得參加一次 PyCon US 會是一個更佳的選項。
